## 🎮 게임 방법

### 혹시 바다거북스프라고 하시나요?

바다거북스프는 **수평적 사고 추리 게임**이에요.
출제자가 기묘한 상황 하나를 들려주면, 참가자는 **"예 / 아니오"로 답할 수 있는 질문**만 던져서 그 뒤에 숨겨진 사연을 추리해요.
이 챗봇에서는 AI가 출제자가 되어 질문에 답해 줘요.

### 1. 목표

한 줄 문제 속에 숨겨진 사연을 추리해서 맞히는 게임이에요.

### 2. 질문하기

아래 입력창에 예/아니오로 답할 수 있는 질문을 하세요. 출제자는 아래 네 가지로만 답해요.

- **예 / 아니오** : 질문 내용이 진상과 맞는지 틀린지
- **상관없음** : 진상과 관계가 없거나 정해져 있지 않은 내용
- **애매함** : 대답하기 애매한 질문

"만약 ~였다면?" 같은 가정 질문도 상관없음으로 처리돼요.

"왜?", "누구야?" 같은 열린 질문에는 "예/아니오만 가능합니다"라고 안내해요.

### 3. 질문 횟수와 힌트

질문은 최대 30번까지 할 수 있어요. 질문을 모두 써도 정답은 제출할 수 있어요.
질문이 5번째, 10번째에 도달하면 왼쪽 사이드바의 힌트 버튼이 차례로 열려요. 버튼을 누르면 팝업으로 힌트를 볼 수 있어요.

### 4. 정답 제출

왼쪽 사이드바에 추리한 내용을 적어 제출하세요. 정답은 3번까지 제출할 수 있어요.
(모바일에서는 화면 왼쪽 위의 화살표를 눌러 사이드바를 열 수 있어요.)

### 5. 끝

정답을 맞히거나 정답 제출 기회를 모두 쓰면 사연을 볼 수 있고 게임이 끝나요.
사이드바의 '포기하기'를 누르면 바로 끝내고 사연을 볼 수 있어요.

### ⚠️ 주의 사항

- 질문 길이 제한은 100자입니다.
- 한 번에 하나의 질문만 해주세요.
  - 한 번에 여러 질문을 하면 AI가 애매하다고 판단해요.
